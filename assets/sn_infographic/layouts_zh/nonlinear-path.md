# nonlinear-path

文字排版随形状跳跃，而非沿直线排列。

## 结构

- 内容以活泼、非线性的路径排列
- 元素分散分布，或由蜿蜒不规则的路线连接
- 阅读顺序通过编号、箭头或视觉线索暗示
- 自然且富有活力的感觉

## 适用场景

- 创意或趣味性教育内容
- 头脑风暴或思维导图式版式
- 面向年轻受众的内容
- 非传统主题展示

## 视觉元素

- 连接内容节点的不规则路径
- 元素大小与方向多变
- 趣味连接件（虚线、箭头、脚印）
- 每个节点配以色彩丰富、各不相同的背景

## 文字摆放

- 标签置于各节点内部或旁边
- 必要时标注阅读顺序编号
- 标题置于醒目的锚点位置

## 推荐搭配

- `kawaii`：可爱俏皮的路径
- `crayon-hand-drawn`：手绘漫游路线
- `storybook-watercolor`：奇幻故事路径
