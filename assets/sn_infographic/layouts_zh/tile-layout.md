# tile-layout

地铁风格的磁贴，带有块状色彩入口。

## 结构

- 大小各异的矩形磁贴网格
- 每个磁贴是一个纯色块，带有图标和标签
- 灵感来自 Windows Metro / Material Design 磁贴系统
- 磁贴可以是 1×1、2×1 或 2×2 单位

## 适用场景

- 应用或功能导航概览
- 分类或主题索引
- 仪表盘入口点
- 颜色编码的分类系统

## 视觉元素

- 醒目的纯色磁贴背景
- 每个磁贴中央的大图标
- 图标下方或上方的简短标签
- 一致的磁贴边框圆角

## 文字摆放

- 标签位于每个磁贴内
- 标签下方可选副标题
- 磁贴组上方的章节标题

## 推荐搭配

- `corporate-memphis`：鲜艳的扁平磁贴网格
- `high-contrast-ad`：高对比度色块
- `pixel-art`：复古磁贴式界面
