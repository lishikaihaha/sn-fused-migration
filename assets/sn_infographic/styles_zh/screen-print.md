# screen-print

丝网印刷叠印效果与质感。有限色彩、刻意套印不准，以及强烈的图形冲击力。

## 配色

- 主色：2–4 种专色，无渐变
- 背景：纸张底色（白色、米色或彩色）
- 点缀：颜色重叠处的叠印混合产生新色调

## 视觉元素

- 大胆、高对比度的图形形状
- 刻意的色彩套印不准（图层之间轻微偏移）
- 用于色调变化的半调网点
- 边缘的油墨洇散和轻微粗糙感
- 实色区域中可见的网版纹理
- 强烈的剪影和图形简化
- 海报式构图

## 字体

- 粗体、窄体展示字体
- 略显粗糙或手绘感的字形
- 可使用模板风格字体
- 文字作为图形元素处理

## 适用场景

音乐与演唱会内容、行动主义与社会议题、反文化主题、DIY 与创客文化、大胆的编辑宣言
