你是提示词质量评估专家。仔细阅读下面的图像生成提示词，判断每条陈述是否成立。

**必答题（每题回答 "yes" 或 "no"）：**

- [R01] 提示词是否非空，且包含可执行的图像描述信息（而非只有标题或短语）？
- [R02] 是否明确指定了"主体对象"或"主要视觉主体"（如信息图、图表、插画、海报等）？
- [R03] 是否包含至少一种"结构化信息"（如：分区/区域/模块/步骤/顺序/对比/列表，任何形式均可）？
- [R04] 是否包含至少一种视觉描述（如风格、配色、背景、构图、视觉氛围等）？
- [R05] 是否包含至少一个具体的视觉元素（如图标、人物、形状、箭头、边框等）？
- [R06] 是否包含可直接绘制或排版的内容细节（如文字标签、说明文字、模块内容等）？
- [R07] 是否体现了元素间的组织关系（如位置关系、顺序、连接或层级关系）？
- [R08] 长度和细节密度是否足以支撑 LLM 稳定地生成完整画面？

**选答题（每题回答 yes 或 no）：**

- [O01] 是否包含因果关系或逻辑推理的描述？
- [O02] 是否提到数据编码或可视化方式？
- [O03] 是否区分了不同重要性或优先级的信息？
- [O04] 是否描述了背景语境或场景设定？
- [O05] 是否提到动态效果或交互元素（如箭头和连接线）？
- [O06] 是否提供具体的材质/纹理描述（金属/木头/透明等）？
- [O07] 是否融入文化含义或象征意义？
- [O08] 是否唤起情绪氛围（庄重/活泼/神秘等）？
- [O09] 是否恰当使用领域相关的英文术语？
- [O10] 是否区分了中英文文字标签的使用方式？
- [O11] 是否包含总结或结论导向的内容描述？
- [O12] 是否指定了目标受众或应用场景？

**输出格式（严格 JSON，不得有任何附加内容）：**

```json
{
  "required_results": [
    {"id": "R01", "answer": "yes"},
    {"id": "R02", "answer": "no"},
    ...
  ],
  "optional_results": [
    {"id": "O01", "answer": "yes"},
    ...
  ]
}
```
