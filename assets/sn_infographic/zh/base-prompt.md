按以下规范创作专业信息图：

## 图像规格

- **Type（类型）**：信息图
- **Layout（布局）**：以 user 消息「## 选中版式」节注入的定义为准（${2.layout_zh}/${2.layout}）
- **Style（风格）**：以 user 消息「## 选中风格」节注入的定义为准（${2.style_zh}/${2.style}）
- **Aspect Ratio（宽高比）**：终稿不描述——由链路渲染配置决定，提示词中不出现
- **Language（语言）**：${3.user_language}（随 user 消息「用户语言」行传入）

## 核心原则

- 信息架构严格遵循布局结构
- 风格美学全程一致应用
- 内容涉及敏感或版权人物时，创作风格相似的替代形象
- 信息保持简洁，突出关键词与核心概念
- 留白充分，以保证视觉清晰
- 保持清晰的视觉层级（主要、次要、支撑三级分明）

## 视觉元素

信息图必须包含与主题语义相关的具体元素：
- 至少一组与主题对应的主插画或图标集
- 每个分区/模块有区分性视觉标记（形状、边框或徽章）
- 背景纹理：终稿按经验 6 显式描写（纹理质感复合词，不写纯底色）
- 字体风格：终稿按经验 6 逐层级显式指定（绝不描述字号）

## 文字要求

- 主标题清晰可读
- 关键概念做视觉强调（加粗或标注框）
- 标签清晰可读
- 全部文字使用指定语言
- **硬数据（数字、日期、专有名词）必须以视觉区分形式呈现：加粗、标注框或数据徽章**

## 布局指南

以 user 消息「## 选中版式」节注入的版式定义为准（Structure/Text Placement 等空间条款），按经验 4 优先级链执行（用户明示布局 > 版式定义 > 自行推断）。

## 风格指南

以 user 消息「## 选中风格」节注入的风格定义为准，按经验 5 优先级链执行（用户明示风格 > 风格定义 > 自行赋予；色板条款按安全红线剥离）。

## 配色

不指定具体颜色。不出现色号、色名或配色方案，颜色交由整体风格统一呈现。
